🔌 ENDPOINTS API IMPLEMENTADOS (15 endpoints)
═════════════════════════════════════════════════════════════════════════════════

SALUD & INFO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  GET   /                     → Información de la API
  GET   /health               → Verificación de salud

DISPOSITIVOS IoT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  POST  /api/v1/dispositivos              → Crear dispositivo
  GET   /api/v1/dispositivos              → Listar todos
  GET   /api/v1/dispositivos/{id}         → Obtener específico

LECTURAS DE SENSORES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  POST  /api/v1/lecturas                  → Registrar lectura (desde ESP32)
  GET   /api/v1/lecturas/actual           → Última lectura + estado
  GET   /api/v1/lecturas/estadisticas     → Datos para gráficos

ALERTAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  GET   /api/v1/alertas/recientes         → Alertas no resueltas
  GET   /api/v1/alertas/dispositivo/{id}  → Alertas de dispositivo
  PATCH /api/v1/alertas/{id}/resolver     → Resolver alerta

MISIONES (Gamificación)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  GET   /api/v1/misiones                  → Listar activas
  GET   /api/v1/misiones/{id}             → Obtener específica
  POST  /api/v1/misiones                  → Crear misión
  PATCH /api/v1/misiones/{id}/progreso    → Actualizar progreso

📊 MODELO DE DATOS (PostgreSQL)
═════════════════════════════════════════════════════════════════════════════════

TABLA: dispositivos
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  id (PK)           VARCHAR(50)       Ej: ESP32_AULA_1
  nombre            VARCHAR(255)      Ej: Sensor Aula de Ciencias
  ubicacion         VARCHAR(255)      Ej: Laboratorio de Biología
  limite_co2        INT (def: 900)    Límite CO2 en ppm
  limite_pm25       INT (def: 25)     Límite PM2.5 en µg/m³
  ultimo_contacto   TIMESTAMP         Último ping del dispositivo

TABLA: lecturas
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  id (PK)           BIGINT            Autoincremental
  dispositivo_id    VARCHAR(50)       FK → dispositivos
  fecha_hora        TIMESTAMP         Cuándo se tomó la lectura
  temperatura       NUMERIC(4,2)      En °C
  humedad           NUMERIC(5,2)      En %
  pm1_0, pm2_5...   NUMERIC(5,2)      En µg/m³
  voc               INT               Compuestos volátiles (ppb)
  co2               INT               Dióxido de carbono (ppm)

  [ÍNDICE] idx_lecturas_dispositivo_fecha (dispositivo_id, fecha_hora DESC)

TABLA: historial_alertas
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  id (PK)           INT               Autoincremental
  dispositivo_id    VARCHAR(50)       FK → dispositivos
  fecha_hora        TIMESTAMP         Cuándo se generó
  variable_afectada VARCHAR(50)       PM2.5, CO2, PM10, VOC
  valor_detectado   NUMERIC(5,2)      Valor que superó límite
  nivel_critico     VARCHAR(10)       ALTA o MEDIA
  resuelto          BOOLEAN           ¿Fue resuelta?

TABLA: misiones_usuario
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  id (PK)           INT               Autoincremental
  titulo            VARCHAR(255)      Ej: Cuidar el aire del aula
  categoria         VARCHAR(100)      Ej: STEM Ciencias
  progreso          INT (0-100)       Porcentaje de avance
  activa            BOOLEAN           ¿Está activa?

🚀 CÓMO EMPEZAR (5 MINUTOS)
═════════════════════════════════════════════════════════════════════════════════

1. CREAR ENTORNO VIRTUAL Y INSTALAR DEPENDENCIAS:
   ───────────────────────────────────────────────────────────────────────────
   $ cd vision_air_api
   $ python -m venv .venv
   $ .venv\Scripts\activate         # Windows
   $ pip install -r requirements.txt

2. CONFIGURAR BASE DE DATOS:
   ───────────────────────────────────────────────────────────────────────────
   $ cp .env.example .env
   $ # ✏️  Edita .env con tus credenciales PostgreSQL

   $ createdb -U postgres dusty_monitor
   $ psql -U postgres -d dusty_monitor -f migrations/001_initial_schema.sql

3. EJECUTAR LA API:
   ───────────────────────────────────────────────────────────────────────────
   $ python main.py

   ✅ API ejecutándose en: http://localhost:8000

4. ACCEDER A LA DOCUMENTACIÓN INTERACTIVA:
   ───────────────────────────────────────────────────────────────────────────
   🌐 Swagger UI: http://localhost:8000/docs
   📖 ReDoc:      http://localhost:8000/redoc
   
   Aquí puedes probar todos los endpoints sin escribir código!

📈 TECNOLOGÍAS UTILIZADAS
═════════════════════════════════════════════════════════════════════════════════

Backend Framework:    FastAPI 0.104.1         (Moderno, rápido, con type hints)
Web Server:           Uvicorn 0.24.0          (ASGI, async/await)
Base de Datos:        PostgreSQL              (Relacional, confiable)
ORM:                  SQLAlchemy 2.0.23       (Abstracción de BD)
Validación:           Pydantic 2.5.0          (Type validation, JSON schema)
Environment Vars:     python-dotenv           (Gestión de .env)
Driver PostgreSQL:    Psycopg2 2.9.9          (Conexión a PG)
Testing:              Pytest                  (Framework de tests)
Linting:              Black, Flake8, Isort    (Calidad de código)
Production Server:    Gunicorn 21.2.0         (WSGI, multi-worker)
